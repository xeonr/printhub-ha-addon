# Print Hub for Home Assistant

[![Add this repository to Home Assistant](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2Fxeonr%2Fprinthub-ha-addon)

Add-ons for [Print Hub](https://printhub.xeonr.io).

- **[Print Hub worker](printhub_worker/DOCS.md)**: lets Print Hub reach the 3D
  printers on your home network. Runs on aarch64 (Raspberry Pi 4/5, most
  boxes), amd64 and armv7.

To add this repository by hand: **Settings → Add-ons → Add-on store → ⋮ →
Repositories**, and enter `https://github.com/xeonr/printhub-ha-addon`.

The images are built by Print Hub's own pipeline from the worker's source; this
repository holds only the add-on's description and is updated from there.
Mirrored from git.prod.wtf/xeonr/print-hub/ha-addon: open issues on GitHub.
